# abstractions

Набор интерфейсов, через которые компоненты Sudzekai Web OS взаимодействуют друг с другом без жесткой зависимости от конкретных реализаций.

## Установка

```bash
go get github.com/sudzekai-web-os/abstractions@latest
```

## Основные интерфейсы

- `IConfiguration` — чтение и настройка значений конфигурации.
- `IExecutor` — выполнение команд и команд в указанной директории.
- `IHandlersRegistry` — регистрация HTTP-маршрутов, middleware и фильтров ответов.
- `ILogger` и `ILoggerFactory` — логирование и создание именованных логгеров.
- `IModule` — контракт динамического модуля: имя, версия, описание и инициализация.
- `IModulesLoader` — загрузка модулей и получение списка загруженных модулей.
- `IServer` — запуск, остановка и настройка HTTP-сервера.

Пакет использует типы из `github.com/sudzekai-web-os/types` для результатов команд, HTTP-обработчиков и middleware.

## Пример модуля

Модуль должен экспортировать переменную `Module`, реализующую `IModule`:

```go
var Module abstractions.IModule = myModule{}
```

Метод `Initialize` получает реестр обработчиков, фабрику логгеров и исполнитель команд.
